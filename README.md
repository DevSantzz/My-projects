🐍 Projetos Python

Coleção de projetos desenvolvidos em Python para praticar lógica de programação, estruturas condicionais, funções, listas, dicionários e manipulação de arquivos.

📂 Projetos
📁 Organizador de Arquivos

Organiza arquivos automaticamente em diferentes pastas de acordo com seus tipos.

Exemplos:

Imagens → Imagens/
Documentos → Documentos/
Vídeos → Videos/
Músicas → Musicas/
💰 Calculadora de Lucro

Calcula o lucro obtido a partir do preço de custo e do preço de venda de um produto.

Calcula:

Preço de custo
Preço de venda
Lucro
Margem de lucro
📝 Analisador de Texto

Analisa um texto digitado pelo usuário e apresenta algumas informações.

Funções:

Conta caracteres
Conta palavras
Converte para letras maiúsculas
Converte para letras minúsculas
Permite analisar até 20 linhas
📦 Sistema de Estoque

Sistema simples para controlar produtos de um estoque.

Funções:

Cadastrar produtos
Listar produtos
Adicionar quantidade
Remover quantidade
Excluir produtos
Mostrar preço e valor total do estoque
👤 Sistema de Cadastro

Sistema para cadastrar e visualizar pessoas.

Informações cadastradas:

Nome
Idade
E-mail

▶️ Como executar
Instale o Python 3.
Baixe ou clone este repositório.
Entre na pasta do projeto.
Execute o arquivo Python desejado:
python nome_do_arquivo.py


No Windows, também pode ser necessário utilizar:

py nome_do_arquivo.py

O objetivo deste projeto é praticar e desenvolver conhecimentos em Python e lógica de programação, criando pequenos sistemas úteis para situações do dia a dia.

## 📌 Sobre

Programa desenvolvido em Python para organizar automaticamente
arquivos em diferentes pastas de acordo com suas extensões.

## ⚙️ Funcionalidades

- Identificação de extensões
- Criação automática de pastas
- Organização dos arquivos
- Suporte a diferentes formatos

## 🛠️ Tecnologias

- Python
- OS
- Shutil

## ▶️ Como executar

```bash
python main.py
